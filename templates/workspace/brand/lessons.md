# Lessons

Every correction you give becomes a written rule here, the same day. Chat is not memory: if a note only lives in a conversation, the agents will forget it tomorrow. If it's written here, every agent follows it from then on.

You rarely edit this file by hand. Tell Claude what was wrong (or use `/attention:lesson <what to change>`) and it adds a dated rule. Rules that keep coming up get promoted into the agents' skills, and a weekly clean-up removes rules that are stale or contradict each other.

## Format

One rule per line:

```
- YYYY-MM-DD · the rule, written as an instruction · why, or the evidence
```

Example:

```
- 2026-10-14 · Never open a video with "So," · sounded hesitant in two reviews
```
