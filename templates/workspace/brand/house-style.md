# House style for edits

Every video edit inherits these rules. The Art Director reads this file before planning a cut, and your feedback on edits gets written here (or into `lessons.md`) so you never give the same note twice.

## Pacing

- No pause longer than 0.15 seconds unless it is there on purpose.
- The hook (first 3 seconds) is never cut into.
- When you repeat a line, the last full take wins.
